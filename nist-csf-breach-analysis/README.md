# Yahoo Breach Analysis Using NIST CSF 2.0

## Overview
This project analyzes the Yahoo data breach through the lens of the NIST Cybersecurity Framework 2.0. The report focuses on how limited adherence to the Protect and Respond functions contributed to the scale and severity of the incident.

## Objectives
- Analyze a major real-world breach using NIST CSF 2.0
- Identify key control and policy failures
- Recommend security improvements aligned with the framework

## Skills Demonstrated
- NIST CSF 2.0 analysis
- Security control evaluation
- Incident analysis
- Governance and response planning
- Risk-based recommendations

## Key Findings
- Weak password protection practices and inconsistent hashing increased exposure
- Access control weaknesses enabled unauthorized access
- Delayed breach disclosure reflected major failures in incident response
- Stronger authentication, monitoring, vulnerability management, and response planning could have reduced impact

## Deliverables
- NIST CSF 2.0 breach analysis report
- Control and policy checklist
