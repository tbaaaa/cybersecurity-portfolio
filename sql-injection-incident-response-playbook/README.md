# SQL Injection Incident Response Playbook

## Overview
This project develops an incident response playbook for a hypothetical SQL injection breach in a healthcare environment. The scenario involves exfiltration of patient data through a vulnerable web-based portal.

## Objectives
- Explain SQL injection and how it occurs
- Analyze possible root causes and control failures
- Develop a practical incident response workflow
- Identify tools, personnel, and prevention improvements

## Skills Demonstrated
- Incident response planning
- SQL injection analysis
- Security playbook development
- Detection and containment strategy
- Recovery planning
- Lessons learned documentation

## Key Findings
- Lack of parameterized queries and weak server-side validation increased exploitability
- Over-privileged database access increased data exposure
- Missing or ineffective WAF protections reduced detection capability
- A structured playbook improves readiness across preparation, detection, containment, eradication, recovery, and post-incident review

## Deliverables
- SQL injection attack analysis
- Incident response playbook
- Flowchart
- Tool and personnel recommendations
