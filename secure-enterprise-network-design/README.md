# Secure Enterprise Network Architecture Design

## Overview
This project documents the design of a secure and resilient enterprise network for a small startup company using Cisco Packet Tracer. The architecture emphasizes segmentation, scalability, redundancy, secure wireless access, and defense in depth.

## Objectives
- Design a segmented network for multiple departments
- Reduce single points of failure
- Support secure internal services and internet connectivity
- Apply practical security controls such as firewalls, DMZ placement, and IDPS recommendations

## Skills Demonstrated
- Network segmentation
- VLAN design
- OSPF routing
- Firewall rule planning
- DMZ architecture
- Resilience and redundancy design

## Key Features
- Department-level segmentation using VLANs and subnets
- Redundant routers and EtherChannel links
- OSPF dynamic routing for failover
- Guest wireless isolation
- DMZ placement for DNS, DHCP, mail, and application servers
- Firewall policy recommendations
- IDPS recommendation for enhanced monitoring
